# Killin' in Comedy — read before every change

A roguelike deckbuilder about being a stand-up comedian: Slay the Spire
structure, Balatro-style scoring, and the craft of a stand-up set (setup →
punchline → tag, reading the room, beating the light) as the core system.
Godot 4.3, GDScript only.

Samuel builds from his phone: Claude writes and pushes the code, GitHub builds a
web version, and he playtests it in Safari. Keep replies short and in plain words,
and handle git, builds and fixes yourself.
**End every reply with the play link:** https://humble-house-studios.github.io/killin-in-comedy/

## The scaling rule
The web build in Safari is the test for every platform. If it looks and plays
right there, it's right on iPhone, Android and Steam. To keep that true:

- **Phones = vertical. Steam = horizontal.** Same game, same code, two layouts.
  - Base resolution 720×1280, stretch mode `canvas_items`, aspect `expand`.
    When the screen is wider than tall, `main.gd` swaps the base to 1280×720
    so text stays readable sideways.
  - Mobile exports lock to portrait (`display/window/handheld/orientation`).
  - Desktop opens a 1280×720 window (`window_width_override.pc` /
    `window_height_override.pc`).
  - The UI picks its layout from the screen shape (wider than tall = landscape
    layout) and switches live on resize. Build it from Control nodes, anchors
    and containers, never fixed pixel positions.
  - Testing both on a phone: hold it upright for the mobile layout, turn it
    sideways for the Steam layout.
- **Compatibility renderer everywhere**, so the web build looks exactly like the
  shipped apps. The game isn't graphics-heavy, so nothing is lost.
- **Nothing web-only.** No browser-only APIs; anything platform-specific is
  wrapped in `OS.has_feature(...)` with a working fallback.
- **Touch and mouse both work** for every action; touch targets at least 88 px
  tall at 720 wide (cards in hand included). Respect the phone's safe area so
  nothing hides under the notch.
- **Stay light:** web build under ~30 MB, no reliance on threads.

## Code structure
- Game logic in `res://engine/`, with no scene dependencies, tested headless
  with GUT.
- Cards, audiences and map nodes are `.tres` Resources in `res://data/`.
- All game numbers in `res://engine/balance.gd` so they can be tuned in one place.
- Balance check: `godot --headless -s res://tools/tune.gd` plays 300 autopilot
  runs and prints win rates per set (`TUNE="open_mic=100:4"` overrides targets).
- Placeholder art only: colored panels and labels. No image generation.
- Ask before adding any addon beyond GUT.
- Sounds and music are generated by `tools/make_audio.py` (numpy + ffmpeg);
  re-run it after editing. Effects are WAV, the music loop is OGG.
- The club look is drawn in code: `scenes/club.gdshader`, `scenes/stage.gdshader`
  and `scenes/stage_view.gd` (mic and crowd). Jokes live in `data/jokes.gd`.

# MVP

## Goal
Prove the core loop is fun in under 10 minutes on a phone:
**pick a path → play a set (card battle) → earn a card → repeat → headline show (boss).**

## Core rules: the set
- **The set = a battle.** Each audience needs a number of **laughs** to win.
- **The Light (the clock):** every set lasts a fixed number of **minutes**; one
  turn = one minute. Reach the laugh target before your time is up or you
  "get the light" and lose the run.
- **Heat** (Crowd Energy) is the multiplier: ×(1 + Heat ÷ 10), so Heat 10 = ×2.
  It drifts down 1 a minute, bombing (a minute with no laughs) costs 2 more,
  and at 0 you "lose the room" and lose the run.
- **Each minute you build a bit.** Cards add laughs to the bit; press
  **Land It** to score it: **bit laughs × multiplier**, Balatro-style. The bit's
  multiplier is Heat plus every chain link you made this minute.
- **Joke structure chains:** joke cards have a beat: **Setup → Punchline → Tag → Tag…**
  Playing a card in the right beat after the last joke card is a **chain link:
  +0.5× to this bit.** Other cards (crowd work, notes, water) don't break a chain.
  A Setup also doubles the next Punchline.
- **Read the room:** every joke card has a **topic** (Dating, Family, Work,
  Tech, Food, Animals), rolled when the card joins your deck. Each audience
  **loves** some topics (×1.5 laughs, +1 Heat) and **hates** others
  (×0.5 laughs, −1 Heat). Shown on the audience panel.
- **Mic time** = 3 per minute. **Hand:** draw 5, discard when the bit lands.
- **Audience intents:** each minute the audience shows its next move (e.g.
  "Heckler: −5 Heat", "Ordering drinks: −1 mic time next minute").

### Starter cards
| Card | Cost | Beat | Effect |
|---|---|---|---|
| Setup | 1 | Setup | Next Punchline deals double |
| Punchline | 1 | Punchline | +6 laughs |
| Topper | 1 | Tag | +4 laughs; +3 more if it isn't your first card this minute |
| Crowd Work | 1 | — | +3 Heat, reveal the next audience move |

Starter deck: 4× Punchline, 3× Topper, 2× Setup, 1× Crowd Work.
Reward pool: the other cards in `data/cards/` (one line of rules each).

## Scope
**In:** 1 class ("The Club Comic"), the career ladder of sets (Open Mic →
club spots → Headline Show boss), 3 audiences + 1 boss, pick-1-of-3 card
rewards, win/lose/restart, text speech bubbles for card plays.

**Out (later):** targetable hecklers in the crowd; material going stale across
a run + Writing Session nodes that fuse two cards into a new bit; relics
(Lucky Mic, The Notebook, A Manager); the other four comedian classes
(Observational, Storyteller, One-Liner, Crowd Worker, Absurdist); career map
with branching paths; Mad Libs Career Cutaway; voiced Bubble Voice System;
final art; saves.
